# Sourced 3D models

Sculpted or scanned models some HQ dioramas use for their statues and sculpture (a figure built from code can't reach the
quality the set needs). Each folder holds one model as downloaded, unchanged, and a `SOURCE.md` with
its author, link and licence. Only CC0 or CC BY (Creative Commons Attribution) models: never
NonCommercial (the site charges for plans) or NoDerivatives (the model is restyled and placed in a
diorama). A CC BY model's credit goes with its picture wherever the site shows it.
